В настройках PDF появился необязательный внешний обработчик имени. Применяется при сохранении и извлечении страниц. Программа получает значение QR или количество страниц через стандартный ввод в UTF-8 и возвращает одну строку через стандартный вывод. При отсутствии результата Nicy предлагает обычное имя.

Для документов с номером вида 39/30-н/39-2026-2-291 скачайте отдельный QrName.exe. Откройте настройки PDF, включите «Имя файла из внешней программы», выберите QrName.exe и «Значение QR-кода». Аргументы оставьте пустыми. Для этого примера предлагается 2026-2-291.pdf. Обработка выполняется локально.

В «Полях для заполнения» можно вставить $(external) и сочетать его с датой и номером. Для Lua или Python выберите исполняемый файл интерпретатора и укажите путь к скрипту в аргументах.

Доступны переносимая сборка и неподписанный установщик для Windows x64.
